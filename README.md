# mglearn.github.io

The landing page for **mglearn** — free, self-contained classroom learning
resources built by Miguel Guhlin for TCEA. Served at
<https://mglearn.github.io/>.

It's a single static `index.html` (navy & gold, no build step) that links out
to the individual project sites, each of which lives in its own repo and
publishes under this account:

| Resource | Path | Repo |
| --- | --- | --- |
| Learning Activities Hub | [/activities/](https://mglearn.github.io/activities/) | `mglearn/activities` |
| Suffrage Sojourn | [/sojourn/](https://mglearn.github.io/sojourn/) | `mglearn/sojourn` |
| TCEA Vibe-Coded Solutions | [/tcea/](https://mglearn.github.io/tcea/) | `mglearn/tcea` |
| AI for the Defense (TCDLA) | [/legalai/](https://mglearn.github.io/legalai/) | `mglearn/legalai` |
| Getting to Know You | [/gtky/](https://mglearn.github.io/gtky/) | `mglearn/gtky` |
| Digital Citizenship / Gen AI Literacy | [/digcit/](https://mglearn.github.io/digcit/), [/genailit/](https://mglearn.github.io/genailit/) | now redirect into the Activities Hub |
